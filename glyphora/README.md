# Glyphora

Lingrove 的离线字母学习子应用，结合字形认知、书写练习与小测验。宿主最低版本 1.3.0。

- 日语：46 个平假名、46 个片假名，KanjiVG 笔顺动画。
- 俄语：33 个字母的大小写，印刷体与 Bad Script 手写范字对照。
- 希腊语：24 个字母大小写及词尾 ς，GFS Olga 参考字形。
- 底部三个 Tab：学习、测试、字母；顶部仅保留语言切换。
- 学习：开始/继续学习打开进度面板，展示已学与未学字母；按观察→描摹→独立书写推进。每种语言及字母组独立保存当前位置、步骤和未提交笔迹，单字复习不改变顺序学习位置。
- 测试：默认已学范围，也可选全部字母；每轮 10 题，5 道书写与 5 道四选一交替，少于 10 个目标时会明确提示重复抽题。干扰项不泄露其他后续目标。每种语言保留一轮未完成测试，切换 Tab/语言或重启后继续。完成后保存总分、分项成绩与作答回顾。
- 字母：完整字母表，俄语并排显示手写体和印刷体。日语使用 KanjiVG 逐笔动画（播放/暂停/重播/逐笔）；俄语、希腊语提供逐步书写方向说明，不声称是统一强制笔顺，也不将字体轮廓伪装为动画轨迹。
- 记录：本机保存最近 500 次学习作答与 50 轮测试；描摹独立记录，不计入独立书写数量。

## 手写

新宿主通过 `handwriting.inline` 将 PencilKit 嵌入 WKWebView 滚动内容中的画板位置，随页面滚动和尺寸变化对齐，并避开顶部工具和底部 Tab。支持仅 Pencil / 允许手指、撤销、整笔橡皮、清空、页内评分和原生矢量笔迹恢复；关闭模块、换字、切换 Tab 会回收对应会话。

浏览器及旧宿主自动使用页内 Canvas，通过 Pointer Events 接收鼠标/笔输入。默认忽略手指触摸，可显式开启。新原生能力需要重新构建安装宿主；仅刷新网页无法更新宿主代码。

进度使用独立的 `progress-v1` 存储键，保留已有历史记录；读取时校验字母 ID、范围、分数、题目和坐标，损坏数据不会自动覆盖。保存按顺序排队，完成测试记录优先于残留草稿。旧记录没有保存的原始笔迹会明确提示。

## 评分的当前边界

这是可用的第一版练习反馈，不是经真实手写数据校准的识别器。字迹与范字栅格化、按包围盒居中等比归一化，使用双向距离、宽高比及过度涂抹惩罚，和同组其他字形比较。低匹配度提示差异；接近多个字形时返回不确定，不声称写对。

当前不评分笔顺、笔压、速度，不使用大模型/OCR，不支持完整单词连写、汉字、浊音扩展。俄语和希腊语采用一种参考字体，尚未覆盖所有合理手写变体。上线高置信度自动判定前，应使用真实 Apple Pencil 多人样本校准，并增加校对过的变体模板。

## 开发与验证

```sh
npm run dev -w glyphora
npm run test -w glyphora
npm run check
npm run debug:serve
```

调试服务使用统一 `dist/`，构建后 `/glyphora/` 与 `/sentra/` 同时可用。新宿主原生能力需要重新安装宿主，后续网页改动可直接刷新子应用。

原生集成测试：`LingroveUITests/testGlyphoraNativeWritingAndHistory`，覆盖页内原生落笔、重启恢复笔迹、提交描摹评分、测试 Tab 和字母详情。运行时测试同时覆盖桥接与按会话回收。

## 素材

Logo 为此前确认的绿色 Glyphora 图稿，原图保留在 `public/logo.png`。使用内置 imagegen 生成；最终编辑提示为保留米白手写 g 的轮廓、大小与位置，将背景改为主题绿 #304E3E，去除光晕与透明伪影。

所有第三方字形的署名和许可在 `public/fonts/THIRD-PARTY.txt`。`src/kana.json` 是 KanjiVG SVG 路径的格式转换，仍按 CC BY-SA 3.0 提供。

## 笔顺说明参考

俄语和希腊语说明是本项目编写的参考动作分解，范字保留字体自身风格，并非临摹字体轮廓。可对照 [Middlebury 俄语手写指导](https://www.middlebury.edu/institute/sites/default/files/2021-01/Russian-handwriting-and-pronounciation-guide.pdf) 与 [Harry Foundalis 希腊语手写说明](https://foundalis.com/lan/hw/grkhandw.htm) 查看不同写法。上述资料的图片未复制到应用中。
