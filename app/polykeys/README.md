# Polykeys 键盘布局

每种语言使用 iPhone 已有的屏幕键盘布局；日语提供罗马字和九宫格假名两种输入方式。有多个选项时优先选择接近 QWERTY 的系统选项；没有该选项时使用系统字母布局，不自行设计音译映射，也不为凑齐 QWERTY 行宽添加按键。

| 语言 | 选择的布局 |
| --- | --- |
| 英语 | QWERTY |
| 法语 | 用户 iPhone 截图中的 QWERTY，第二行末尾保留撇号；重音字母单独显示 |
| 德语 | 用户 iPhone 截图中的 QWERTZ，主键区保留 ü、ö、ä，扩展区提供 ß |
| 西班牙语 | 西班牙语 QWERTY，保留主键区的 ñ |
| 葡萄牙语 | 用户 iPhone 截图中的 QWERTY，重音字母单独显示 |
| 意大利语 | QWERTY |
| 土耳其语 | 系统 QWERTY，而非带额外独立按键的 Türkçe Q 或 F |
| 俄语 | QWERTY / ЯШЕРТЫ，保留 э、ж、щ、ь、ю 的独立位置 |
| 乌克兰语 | 用户 iPhone 截图中的 ЙЦУКЕН，三行末尾分别保留 ї、撇号、ґ |
| 希腊语 | 用户 iPhone 截图中的希腊字母布局，首行以 ε 开头、以重音键结束；ς 和重音字母单独显示 |
| 日语 | QWERTY 罗马字输入和九宫格假名滑动输入，可在编辑区下方切换并保留文字；支持平假名/片假名、促音、拗音、拨音和小假名，不提供汉字候选 |
| 格鲁吉亚语 | 用户 iPhone 截图中的三排布局，Shift 切换七个扩展字母，不作为大小写转换 |
| 亚美尼亚语 | 用户 iPhone 截图中的四排布局，保留 և 独立键，支持 Shift 和大写锁定 |
| 韩语 | 标准两式，辅音、元音按系统键位组字 |

日语九宫格采用点按中央、左/上/右/下滑动选择的方式，每个键展示五个方向的假名。小゛゜循环切换前一个假名的浊音、半浊音和小假名；键盘 Tab 定位到按键后，Enter/空格输入中央字符，方向键输入对应方向字符。取消手势不会输入字符，不支持连续点按轮换。

扩展区为系统长按或变体输入的字符提供直接点击入口，例如俄语 ё、ъ 和希腊语 ς、ά。不得把系统主键区已有的字母移入扩展区。符号页和功能按钮沿用应用的公共交互，不承诺复刻系统候选词、预测输入或按键尺寸。

核对资料（2026-10-22）：

法语已按用户提供的 iPhone 小写键盘截图校对：`qwertyuiop`、`asdfghjkl'`、`zxcvbnm`。`àâæçéèêëîïôœùûüÿ` 作为独立扩展按键显示，支持 Shift 大写。

德语已按用户提供的 iPhone 小写键盘截图校对：`qwertzuiopü`、`asdfghjklöä`、`yxcvbnm`。采用用户确认的 QWERTZ 布局，`ß` 单独显示在扩展区。

葡萄牙语已按用户提供的 iPhone 小写键盘截图校对：`qwertyuiop`、`asdfghjkl`、`zxcvbnm`。主键区保持不变，重音字母保留独立扩展按键。

乌克兰语已按用户提供的 iPhone 小写键盘截图校对：`йцукенгшщзхї`、`фівапролджє'`、`ячсмитьбюґ`。ї、ґ 和撇号都在主键区，不重复设置扩展区。

希腊语已按用户提供的 iPhone 小写键盘截图校对：`ερτυθιοπ΄`、`ασδφγηξκλ`、`ζχψωβνμ`。首行末尾的 `΄` 直接输入重音符号；带重音元音和词尾 `ς` 在扩展区直接输入。

格鲁吉亚语按用户提供的普通态与 Shift 态截图校对：普通态为 `ქწერტყუიოპ`、`ასდფგჰჯკლ`、`ზხცვბნმ`；Shift 态为 `ქჭეღთყუიოპ`、`აშდფგჰჟკლ`、`ძხჩვბნმ`。Shift 输入后恢复普通态，不将字母转换为 Mtavruli 大写。两种状态共覆盖现代格鲁吉亚语的 33 个字母。

亚美尼亚语按用户提供的大小写截图校对：`էթփձջևրչճժշ`、`քոեռտըւիօպխ`、`ասդֆգհյկլծ`、`զղցվբնմ`。全部 39 个字母（含 և）保留在四排主键区，不移到扩展区；և 大写为 ԵՒ。
