# Morphora · 多语言手册

应用目录与模块 ID 为 `morphora`，工作区包名为 `@lingrove/morphora`。首批提供日语与现代希腊语。顶部选择学习语言，底部统一为「变形速查 / 语法手册」，界面及内置教材支持简体中文、英语、日语，跟随 Lingrove 的语言与外观设置。

- 变形速查：日语保留学校文法六种活用形与教育文法常用表达；希腊语按词类查询，动词展示人称、数、时态、体和语气，名词、形容词、冠词和代词展示适用的性、数、格。不变词只提供原形与例句。已变形输入还原基本形式。
- 语法手册：日语保留文法基础、词类、敬语系统；现代希腊语提供词类总览、冠词与四种格、名词、形容词、代词、动词、时态与体、语气与否定、副词、介词、连词与句法，共 11 章。两种手册均可离线阅读。
- 离线变形示例：日语「食べる」；希腊语 γράφω（26 项常用主动形式）、καλός（三性、两数、四格，共 24 项）、φίλος（单复数四格，共 8 项）。示例明确标记范围，不代表全部动词形式。

任意单词查询需在 Lingrove 中配置模型。结果在独立二级页显示，隐藏底部导航并通过返回按钮恢复查询；返回时保留输入、取消未完成请求。不同学习语言分别保留输入，两种手册分别保留阅读章节。查询记录暂不持久化。

模型接口统一使用 `groups` 和 `forms[].group`，按目标语言选择提示。只展示完整的流式条目；取消、断流或最终校验失败时保留已显示内容，并标为部分结果。语法准确性仍需结合语境核对。希腊语参考资料列在手册末尾。

```sh
npm run dev -w @lingrove/morphora
npm run test -w @lingrove/morphora
npm run build
```

根目录 Debug 构建会同步生成目录、ZIP 和 iOS 内置资源。纯 Web 修改无需重新安装 iOS，在设置按钮旁点击「重新加载子应用」即可。
