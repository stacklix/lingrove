# Kotoba · 日语活用

底部「单词查询 / 活用语法」导航沿用 Glyphora / Sentra 的样式。活用语法为内置离线手册，按“动词分类 → 六种学校文法活用形 → 形容词”组织，动词分类在同一章内按五段、一段、サ变、カ变分组，分别讲解原形构成、词尾特征、识别依据和易误判词；教育文法形式和常见例外纳入各章；查询结果继续使用独立二级页面。语法页右上角目录按钮从顶部展开章节目录，点击章节自动收起，保留当前章节高亮。

独立的日语语法子应用。提交查询后进入独立二级结果页，返回查询会保留输入，并取消尚未完成的请求。输入一个日语单词，通过宿主模型识别词性与原形，展示活用形式、假名读音、用法、日语例句和中文翻译。一级通过学校文法活用形页签切换（窄屏自动换行，无需横向滚动），二级展示所选活用形的教育文法常用形式与例句，支持隐藏读音。

- 动词：辞书、礼貌、否定、过去、て、可能、受身、使役、意向、条件、命令等形式。
- い形容词、な形容词：按各自规则展示常用变化；な形容词注明系词结构。
- 名词等无活用的词：说明无活用，仅展示原形与例句。
- 已活用的输入还原原形；歧义词在说明中标记采用的读音与含义。
- 模型生成内容可能有误，特殊用法应结合语境核对。格式校验不代替语法准确性校验。

在 Lingrove 宿主设置中配置模型后即可查询。浏览器只能预览界面和内置「食べる」15 项形式与用法示例。查询记录暂不保存。支持流式展示完整条目；取消、断流或最终校验失败时，已显示内容会保留并标记为部分结果。兼容日文活用名称、snake_case 字段及嵌套形式；缺少可选读音不会丢弃整份结果，缺失词形、例句、译文或父分组仍会明确报错。

```sh
npm run dev -w @lingrove/kotoba
npm run test -w @lingrove/kotoba
npm run build
```
