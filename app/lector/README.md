# Lector · 阅读辅助

首页为文章列表，右上角导入菜单支持粘贴文本和 UTF-8 TXT / Markdown 文件（200 KB 以内）。文章最多 20,000 字符，按句末标点优先切成不超过 240 字符的段落，顺序请求宿主模型；提交后立即加入书架，由应用内任务队列按导入顺序异步分析；全部解析并校验成功后才可阅读。超长单句会拆段。预处理返回使用紧凑数组格式减少输出量；超时、断流等临时错误只对当前段自动重试一次，不无限重试。点击未完成的文章显示已完成段数、状态和暂停/重试入口。关闭进度弹窗、切换 Tab 或阅读其他文章不会取消分析；应用退出或被系统挂起可能中断任务，重新打开会保留原文并标记暂停，继续时复用已校验并保存的分段，仅处理未完成部分。删除待分析文章会取消请求并忽略迟到结果。未确认导入的标题、正文和来源自动暂存，关闭弹窗和重启后恢复；无草稿时为空白，提交到任务队列后清空草稿。

导入阶段仅预生成断句、短语分组与汉字假名注音，不请求词义、结构或翻译。原文不加空格，短语通过下划线区分。点击整句后才请求句子结构分析；Sheet 参考 Sentra，展示中文翻译、句式概括、句子成分（原文、译义、词性、作用）、必要的语法修正和语法要点/活用链。成功结果按文章与句子序号持久缓存并验证原文与缓存版本，下次直接读取；失败不缓存，关闭弹层取消请求并忽略迟到结果。相邻句子作为语境传给模型，但只分析所选原句。旧版文章数据兼容。唯一阅读开关为假名注音。首页不显示额外品牌标题栏，顶部左侧保留宿主 Home 按钮区域；阅读二级页通过 SDK 隐藏 Home。

两个底部 Tab：书架（文章列表）、我的（文章数量、字符数、解析词语数、浏览句子数、前台阅读时长、打开及查看解析次数、文章明细与删除）。浏览句子仅表示曾出现在视口或点击，不代表掌握。数据由模块独立本地存储保存，旧版记录保留，不再自动淘汰第 12 篇以外的文章。写入失败明确提示；超过存储容量时需删除不需要的文章。启动总是进入书架，点击文章后恢复句子位置。

目前支持日语；Reading / Sentence / Token 与语言注册表独立，未来新增语言需添加解析与校验规则。模型结果必须完整还原原文和注音对应词语，格式校验不保证语言学准确性。浏览器可体验示例，实际解析需要 Lingrove 宿主及已配置模型。

```sh
npm run dev -w @lingrove/lector
npm run test -w @lingrove/lector
npm run build
```
